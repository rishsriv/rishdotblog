# Learning technical skills through the internet: a roadmap for beginners

## **The purpose of this document**

To act as a concrete “how-to” manual for self-motivated people who are trying to pick up technical skills

## **Context**

I’m a self-taught programmer and have picked up a number of technical skills over the years. These include everything from machine learning to building iOS apps to data visualization to interactive web apps

I use these skills to make a living, and have founded [a company](https://loki.ai) in which I’m the only employee and code pretty much everything

## Meta-approach

### Start with the basics

When starting out – don’t try to learn what’s “hot”, or what celebrity-developers on YouTube or Twitter are talking about.

Many of those things are useful, but may not be a good starting point for a new developer.

Instead, just focus on learning the basics. If you want to do something related to data, learn the basics of Python. If you want to do anything related to a web application, learn Javascript.

#### **Python**

Python is a language with a very rich ecosystem. You can use libraries that other people have developed and released for free to solve your problems

It is particularly useful if you want to do anything related to data analysis or machine learning in the future

This 4 and a half hour FreeCodeCamp tutorial is probably the best free resource for learning Python

[https://www.youtube.com/watch?v=rfscVS0vtbw](https://www.youtube.com/watch?v=rfscVS0vtbw)

#### **Javascript**

Javascript is a ubiquitous language that can help you do everything from setting up a web application to doing fancy data visualization to building game engines

Javascript used to be something that only front-end developers used, but is now everywhere and should be used if you want to be a full stack developer

This FreeCodeCamp Javascript tutorial is a really good Javascript resource for beginners

[https://www.youtube.com/watch?v=PkZNo7MFNFg](https://www.youtube.com/watch?v=PkZNo7MFNFg)

### Learn the skills to help you do a project in real life

After you get a hang of the basics, learn the skills you need to learn in order to implement a project in real life.

#### Figuring out what skills to learn

Google around and search for reddit threads around what skills to learn for doing what you want to do. Searching for reddit threads is much better than searching the web, IMO. You avoid things that are on top of Google only because of SEP growth hackers, and instead get things that tend to be more useful

#### Evaluating what courses are worth it

Once you know what skills you need to learn, figure out what courses are good for acquiring these skills. Searching on YouTube is a great way to do this. Typically, courses with a lot of views tend to be of high quality.

If you can’t find anything useful on YouTube, try Udemy. Some of the courses in there are of really high quality. Anything by [Angela Yu](https://www.udemy.com/user/4b4368a3-b5c8-4529-aa65-2056ec31f37e/), for example, is worth taking if a free alternative is not available. Be aware that the cost of a course does not typically reflect how good it is. A $20 course can often be better than a $200 course.

### Applying learnings in real-life

Once you have picked up the skills you need, apply what you have learnt to a real life project and share it on the internet! You’ll often get a lot of criticism (constructive and otherwise) when you do this – this is a good thing because it’ll help you get better quickly.

These don’t have to be massive projects. For example, you can simply do a project around web scraping + data analysis + data visualization, and share a simple image on reddit

As an example, when I was starting to learn the basics of data analysis 7 years ago, I shared a simple bar chart of transfer spending by different football clubs on reddit (after scraping some data). I got a fair bit of feedback on it, and eventually improved as a result

[Why most Germans hate RB Leipzig: half the total transfer spending in 2.Bundesliga comes from a newly promoted club. \[data from transfermarkt.com\]](https://www.reddit.com/r/soccer/comments/2d3gnr/why_most_germans_hate_rb_leipzig_half_the_total/?utm_source=share\&utm_medium=mweb)

As you feel more confident, you can also create websites that host your projects and share them!

## Specific example: How I created a roadmap for learning data science

I started learning to code and understand the basics of data science back in 2013. To do this, I first learnt the basics of Python and Javascript. Then, I mapped all the skills I would need to get really good at data science. A summary of this is below. I didn’t aim to learn all of these, but tried to learn as many as I could:

Next, I tried to understand the exact courses I would need to learn these skills. At the time, most of Coursera courses were completely free and there wasn’t a lot of technical content on YouTube – so I tried to learn more from Coursera than anywhere else.

This was my roadmap for learning these skills:

![](/notion/learning-technical-skills-through-the-internet-a-roadmap-for-beginners/untitled-1.png)

Then, I used reddit and freelancing projects to get real-life experience. I shared as much of my work online, and also reached out to people offering to work for dirt cheap. This allowed me to be more confident about being able to apply those skills in production

Lastly, I leveraged these skills to get consulting gigs at fair rates and, eventually, a full time job. And once I had enough savings to support myself for a year, I launched [Loki.ai](http://loki.ai), which thankfully became [a financially sustainable venture](https://rish.blog/Bootstrapping-a-Data-API-company-0-80M-monthly-requests-059154c377294175a772d0fc7c9a9891).

## Being realistic

If you don’t have a technical background, making a living through technical skills is definitely a possibility. A lot of people have walked that path. But remember – it takes time to build your skills.

Much of learning is an S-curve (illustration below)

![](/notion/learning-technical-skills-through-the-internet-a-roadmap-for-beginners/5d8a294a-c7e7-4e36-9ebc-0170755b194b.png)

Source: [https://www.mckinsey.com/business-functions/organization/our-insights/shaping-individual-development-along-the-s-curve#](https://www.mckinsey.com/business-functions/organization/our-insights/shaping-individual-development-along-the-s-curve#)

While most people recognise this intuitively, they don’t recognise that the early part of the S-curve is a slow, painful crawl. You’ll struggle for a while before you’re really able to be productive. But as long as you keep at it and have realistic expectations, you’ll eventually reach hypergrowth.
