# Narrator.ai – Using software to build data-driven narratives

*Podcasts · Analytics, Startups, Technology* · [Source](https://softwareengineeringdaily.com/wp-content/uploads/2021/02/SED1202-Ahmed-Elsamadisi.pdf)

## Summary

### Podcast URL

[https://overcast.fm/+E6UCHB3VA](https://overcast.fm/+E6UCHB3VA)

### What this is

**One-liner**

Applying a combination of Ray Dalio’s Principles, Basic SQL-based Data Analysis, and template-based graphics + text generation (what Samarth and I did at [popper.ai](https://popper.ai)) to web-activity analysis

**More about the company**

Standardizes all web-activity data from multiple sources (Shopify, Segment, Mailchimp etc), and converts everything into an SQL table with 11 columns. Then, runs analysis on this data, and converts it into a long-form narrative with recommendations for how companies can modify user behaviour

This is done using a fairly innovative data modeling approach. More on that below

### My take

This is a really interesting concept. I’m not if this is the best model for analysing web analytics, and would personally not invest money in the company. But the fundamental insight can be applied to so many other things in the market

> 💡 **Fundamental Insight**
> Once data is standardized, analysis+code that is created once can be extended an infinite number of times for different use cases, and return narrative and actionable text that humans can read as reports or slide decks!

### Trends discussed

- Companies are going to start using Data Warehouses much, much sooner — because they’re only getting cheaper and better, and because SaaS is everywhere
- Most AI-generated recommendations right now are shit. “Women convert better than men” is not something that you can do very much with. Taking the time to craft a narrative that is actually useful, insightful, and helps customers is really hard — but it leads to delighted customers (this was something that we also discovered with Popper)
